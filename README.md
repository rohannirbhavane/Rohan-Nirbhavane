### 🚀 About Me
I am an **Aspiring DevOps Engineer** dedicated to automating infrastructure, building secure CI/CD pipelines, and orchestrating scalable containerized environments. I thrive on bridging the gap between development and operations to optimize software delivery workflows.

- ☁️ **Cloud Computing:** Hands-on provisioning scalable architectures on **AWS Cloud**.
- 🏗️ **Infrastructure as Code:** Writing clean, modular **Terraform** configs (VPCs, EC2, S3, Security Groups).
- 🐳 **Containerization & Orchestration:** Package apps with **Docker** and manage workloads via **Kubernetes**.
- 🔁 **Continuous Integration/Deployment:** Engineering automated CI/CD build, test, and scan pipelines via **Jenkins**.
- 🐧 **Foundations:** Deep comfort with **Linux Administration**, shell automation, and structured **Git/GitHub** workflows.
